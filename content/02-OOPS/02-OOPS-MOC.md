# OOPS — MOC

Object-Oriented Programming: model the world as interacting objects. Four pillars: **encapsulation, inheritance, polymorphism, abstraction**.

## Notes
- [[Classes-and-Objects]] — blueprint vs instance, `new`, memory
- [[Constructors]] — default, parameterized, copy, chaining
- [[this-Keyword]] — current object reference
- [[static-Keyword]] — class-level vs instance-level
- [[Inheritance]] — `extends`, single inheritance, `super`
- [[Polymorphism]] — overloading vs overriding, dynamic dispatch
- [[Abstraction-and-Interfaces]] — abstract classes, interfaces, `default` methods
- [[Encapsulation]] — private fields + accessors, why
- [[final-Keyword]] — variable/method/class
- [[Object-Class]] — `toString/equals/hashCode`, the root
- [[Inner-Classes]] — static nested, inner, anonymous, local
- [[Enums]] — type-safe constants, with methods/state
- [[SOLID-Principles]] — design heuristics

> [[Encapsulation]] (bundle+protect) · [[Inheritance]] (reuse) · [[Polymorphism]] (one interface, many forms) · [[Abstraction-and-Interfaces|Abstraction]] (expose essentials, hide details)
